# Mavin's Phone starter

Mobile-first interactive iPhone-style website prototype.

- Lock PIN: `1711`
- Lock screen art: `assets/alohomora-lockscreen.jpg`
- Wallpaper uses the provided GitHub raw URL.
- Apps use fictional/local demo content; no real personal accounts are connected.
- Camera requires HTTPS and browser permission.

## Deploy to Vercel
1. Upload `index.html`, `README.md`, and the `assets` folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Select **Other** as the framework if prompted.
4. Leave the Build Command empty. If asked for an Output Directory, use `.`.
5. Click Deploy.
